# مين أنت في التخصص؟ — لعبة GDGoC DevFest

لعبة أسئلة سريعة: يكتب الطالب تخصصه (عربي أو إنجليزي)، ويجاوب على 5 أسئلة بأربع خيارات ومؤقت 20 ثانية لكل سؤال، ثم يرى نتيجته من 5 مع رسالة تشجيعية.

- 21 تخصصًا × 10 أسئلة + 12 سؤال ثقافة تقنية عامة (222 سؤالًا، كلها بالعربي والإنجليزي ومع شرح).
- مطابقة مرنة للتخصص: تتجاهل الهمزات والتشكيل والتاء المربوطة و«ال»، وتقبل المرادفات (CS، حاسوب، برمجة…) والأخطاء الإملائية الصغيرة. إن لم يوجد تطابق واضح تظهر أقرب 3 اقتراحات، وإن لم يوجد شيء قريب تبدأ أسئلة ثقافة تقنية عامة.
- أصوات مولّدة بـ Web Audio API (بدون ملفات صوتية)، وزر كتم يتذكّر اختيارك.
- واجهة عربية RTL مع زر للإنجليزية، ومتجاوبة للموبايل وشاشة العرض.

## الملفات

| الملف | المحتوى |
|---|---|
| `index.html` | هيكل الصفحة والشاشات الأربع |
| `style.css` | التصميم (ألوان جوجل، Material) |
| `game.js` | منطق اللعبة + **الإعدادات في أول الملف** |
| `sounds.js` | كل الأصوات (Web Audio API) |
| `questions.js` | **بنك الأسئلة** — أضف تخصصات وأسئلة هنا |

## التشغيل

**أسهل طريقة:** افتح `index.html` بالضغط عليه مرتين — يعمل مباشرة في المتصفح بدون أي خادم.

> الخطوط (Google Sans و IBM Plex Sans Arabic) تُحمَّل من Google Fonts، فتحتاج إنترنت لتظهر. بدون إنترنت تعمل اللعبة كاملة بخط النظام.

**أو عبر خادم محلي** (مفيد للتجربة على الموبايل في نفس الشبكة):

```powershell
python -m http.server 8080
```

ثم افتح `http://localhost:8080`.

**على شاشة العرض في الفعالية:** افتح الصفحة واضغط `F11` لملء الشاشة. اللاعب يستطيع الإجابة بالأرقام 1–4 والانتقال بـ Enter.

## النشر (رابط عام للطلاب)

الموقع ملفات ثابتة فقط، فيمكن نشره مجانًا على أي استضافة ثابتة:

### GitHub Pages
1. أنشئ مستودعًا جديدًا على GitHub وارفع الملفات الخمسة (و`README.md`) إلى الجذر.
2. من **Settings → Pages** اختر **Deploy from a branch**، ثم الفرع `main` والمجلد `/ (root)`.
3. بعد دقيقة يصبح الرابط: `https://<اسم-المستخدم>.github.io/<اسم-المستودع>/`

### Firebase Hosting (منصة Google)
```powershell
npm install -g firebase-tools
```
```powershell
firebase login
```
```powershell
firebase init hosting
```
اختر مشروعًا، واكتب `.` كمجلد public، وأجب **No** على سؤال «single-page app» وعلى استبدال `index.html`. ثم:
```powershell
firebase deploy
```

### Netlify Drop (بدون حساب Git)
افتح app.netlify.com/drop واسحب مجلد المشروع كاملًا إلى الصفحة.

> نصيحة: اصنع QR Code للرابط واعرضه بجانب الشاشة ليلعب الطلاب من جوالاتهم.

## التخصيص

### عدد الأسئلة ومدة المؤقت
في أول `game.js`:

```js
const CONFIG = {
  QUESTIONS_PER_ROUND: 5,     // عدد الأسئلة في كل جولة
  SECONDS_PER_QUESTION: 20,   // مدة المؤقت لكل سؤال
  TICK_LAST_SECONDS: 3,       // التكتكة في آخر كم ثانية
  HIGH_SCORE_RATIO: 0.8,      // نسبة النتيجة العالية (confetti)
  DEFAULT_LANG: "ar",         // لغة البداية
  ...
};
```

### إضافة سؤال
داخل `questions` لأي تخصص في `questions.js`:

```js
{
  ar: { q: "نص السؤال؟", options: ["الإجابة الصحيحة", "خطأ", "خطأ", "خطأ"], explain: "شرح قصير" },
  en: { q: "Question?",  options: ["Correct answer",  "Wrong", "Wrong", "Wrong"], explain: "Short explanation" },
},
```

- **الخيار الأول دائمًا هو الصحيح** — اللعبة تخلط الخيارات تلقائيًا.
- رتّب خيارات `en` بنفس ترتيب `ar`. الجزء `en` اختياري.

### إضافة تخصص
انسخ كتلة تخصص كاملة في `questions.js` وغيّر `id` و`icon` و`name` و`aliases` (الكلمات التي قد يكتبها الطالب) والأسئلة. يُفضّل 8 أسئلة أو أكثر.

لتجربة المطابقة افتح Console في المتصفح (F12) واكتب:

```js
GameDebug.match("هندسة كهربا")
```

### الألوان والخطوط
في أول `style.css` داخل `:root`.
